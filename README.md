# Rich人脈富豪俱樂部

| 資料夾 | 用途 | 部署 |
| --- | --- | --- |
| `student/` | 學員網站：登入、註冊、天賦名片、廣場、活動、訊息… | Vercel 專案 1（Root Directory：`student`） |
| `admin/` | 管理後台：統計、學員管理、登入紀錄（只有授權帳號能進） | Vercel 專案 2（Root Directory：`admin`） |
| `supabase/schema.sql` | 資料庫、帳號權限、通關密語檢查、登入紀錄 | 在 Supabase 的 SQL Editor 執行 |
| `build/` | 產生 `student/index.html` 的工具（一般不用動） | — |

## 登入規則

- **註冊**：通關密語＋學員編號＋信箱＋密碼，或「使用 Google 帳號註冊」後補填通關密語與學員編號。通關密語只在註冊時需要，並在伺服器端檢查。
- **登入**：學員編號＋密碼，或 Google 帳號。
- **忘記密碼**：輸入學員編號或信箱，系統寄重設信到註冊信箱。
- **後台**：獨立網址，暫時只有擁有者帳號能進（設定在 `schema.sql` 的 `owner_email()`）。擁有者之後可在後台把其他人設為「檢視者／管理者」，最多 50 位。
- **登入紀錄**：只能新增，任何人都不能修改或刪除。

## 安全說明

- 網頁裡的 Supabase anon key 是公開金鑰，本來就會出現在網頁中；資料安全由資料庫的權限規則（RLS）保護。
- 即使有人看到後台的程式碼或網址，沒有授權帳號也讀不到任何學員資料。
